# Advanced Planting Evidence Rules

เอกสารนี้เป็นส่วนขยายบังคับของ `SKILL.md` และต้องอ่านก่อนวิเคราะห์ Orthomosaic จริง

## 1. เป้าหมายของการตีความ

ห้ามสร้างขอบเขตจาก “ต้นที่ยังมองเห็น” เพียงอย่างเดียว เพราะพื้นที่ที่เคยปลูกอาจมีต้นตาย ต้นหาย หรือภาพถูกบดบัง

ระบบต้องแยกอย่างน้อย:

- `surviving_tree` ต้นที่ยังมองเห็น
- `missing_tree_position` ตำแหน่งในแนวปลูกที่คาดว่าเคยปลูกแต่ไม่พบต้น
- `planting_row` แนวแถวปลูก
- `planting_grid` โครงสร้างกริดหรือระยะปลูก
- `historical_planting_evidence` หลักฐานว่าเคยปลูก แม้ต้นปัจจุบันไม่ครบ
- `natural_vegetation` พืชธรรมชาติที่ไม่มีรูปแบบปลูก
- `open_water` น้ำเปิดที่ไม่มีหลักฐานปลูก
- `canal` คลองหรือร่องน้ำ
- `road_or_dike` ถนน คันดิน หรือแนวพื้นที่ถม
- `unknown_object` สิ่งที่ยังระบุไม่ได้

## 2. ผลลัพธ์ขอบเขต 3 ระดับ

ระบบต้องสร้างผลแยกอย่างน้อย 3 ชั้น:

### `planting_core`

พื้นที่ที่มีความมั่นใจสูง พบต้น แนวแถว ระยะปลูก และความหนาแน่นต่อเนื่อง

### `planting_evidence_boundary`

ขอบเขตที่รวมทั้งพื้นที่ Core และพื้นที่ที่มีหลักฐานว่าเคยปลูก เช่น ช่องว่างต้นตายหรือแนวปลูกที่ขาดบางช่วง

### `uncertain_boundary`

พื้นที่หรือช่วงแนวขอบที่หลักฐานไม่พอ ต้องให้ผู้ตรวจตัดสินใจ

ห้ามบังคับให้ทั้งสามชั้นมีรูปทรงเดียวกัน

## 3. Row and Spacing Analysis

ก่อนสร้าง Polygon ต้องวิเคราะห์:

- ทิศทางหลักของแถวปลูก
- ทิศทางขวางแถว
- ระยะห่างเฉลี่ยและค่ามัธยฐานระหว่างต้น
- ระยะห่างระหว่างแถว
- ความสม่ำเสมอของระยะ
- จุดที่แนวแถวขาดหาย
- จำนวนแนวที่ต่อเนื่องข้ามพื้นที่

ฟิลด์แนะนำ:

```text
row_orientation_deg
cross_row_orientation_deg
median_tree_spacing_m
median_row_spacing_m
spacing_cv
spacing_consistency
row_coverage_ratio
missing_position_ratio
```

ห้ามสรุปว่าเป็นพื้นที่ปลูกจากสีเขียวเพียงอย่างเดียว ต้องมี Pattern หรือหลักฐานอื่นร่วมด้วย

## 4. Mortality Gap

ช่องว่างภายในแปลงไม่ควรถูกตัดออกทันที

ให้จัดเป็น `mortality_gap` เมื่อ:

- อยู่ในตำแหน่งที่สอดคล้องกับกริดปลูก
- มีต้นหรือจุดปลูกอยู่ก่อนและหลังในแนวเดียวกัน
- ไม่มีคลอง ถนน คันดิน หรือสิ่งกีดขวางถาวร
- ขนาดช่องว่างยังสมเหตุสมผลกับระยะปลูก

หากช่องว่างกว้างมากหรือไม่สัมพันธ์กับกริด ให้จัดเป็น `uncertain` หรือ `excluded_area`

## 5. แยกพืชธรรมชาติออกจากต้นปลูก

ลักษณะที่สนับสนุนว่าเป็นพืชธรรมชาติ:

- ระยะห่างไม่สม่ำเสมอ
- ทรงพุ่มมีขนาดหลากหลายมาก
- ไม่ต่อเป็นแถวหรือกริด
- เกาะตามขอบคลองหรือคันดิน
- รูปทรงกลุ่มไม่สัมพันธ์กับแนวปลูกหลัก

ลักษณะที่สนับสนุนว่าเป็นการปลูก:

- มีทิศทางร่วมกัน
- ระยะต้นและระยะแถวใกล้เคียงกัน
- จุดที่หายยังตกอยู่ในตำแหน่งกริด
- มีหลายแถวต่อเนื่องใน Block เดียวกัน
- ลักษณะตรงกับตัวอย่างที่ผ่านการตรวจแล้ว

## 6. Barrier ไม่ใช่ขอบเขตอัตโนมัติ

คลอง ถนน และคันดินเป็น `candidate_barrier` ไม่ใช่คำตอบสุดท้าย

ก่อนใช้เป็นแนวขอบต้องตรวจว่า:

- แนวปลูกสิ้นสุดใกล้ Barrier จริงหรือไม่
- ระยะจากต้นแถวนอกสุดถึง Barrier มากเกินไปหรือไม่
- มีพื้นที่ว่างขนาดใหญ่คั่นหรือไม่
- มีแนวปลูกต่อเนื่องข้าม Barrier หรือไม่
- Barrier เป็นสิ่งกีดขวางถาวรจริงหรือเป็นเพียงความต่างของสีภาพ

หากแนวปลูกสิ้นสุดก่อนคันดินมาก ให้ตามแนวปลูก ไม่ใช่ตามคันดิน

## 7. Segment-Level Confidence

ห้ามให้ Confidence เฉพาะ Polygon ทั้งก้อน

แบ่ง Boundary เป็น Segment และเก็บ:

```text
segment_id
segment_type
start_vertex
end_vertex
confidence
confidence_class
evidence
barrier_type
outer_row_distance_m
requires_review
review_note
```

ระดับแนะนำ:

- 80–100: แนวปลูกและแนวแบ่งชัด
- 50–79: มีหลักฐานแต่มีช่วงขาด เงา น้ำ หรือพืชปะปน
- 0–49: หลักฐานไม่พอ ต้องตรวจ

Preview ต้องใช้สีแยกตาม Confidence:

- เขียว: สูง
- ส้ม: ปานกลาง
- แดง: ต่ำ

## 8. กฎสำหรับภาพลักษณะคล้ายตัวอย่าง

เมื่อพบพื้นที่น้ำตื้นที่มีต้นเรียงเป็นแถว:

1. ใช้แนวแถวและระยะปลูกเป็นหลักฐานหลัก
2. ไม่ตัดพื้นที่กลางแปลงเพียงเพราะมีต้นหายบางส่วน
3. ตรวจพืชหนาแน่นบริเวณขอบว่าเป็นพืชธรรมชาติหรือแนวปลูก
4. ใช้คลองเป็น Barrier เมื่อแยกแปลงอย่างชัดเจน
5. ตรวจว่าคันดินตรงกับแนวต้นแถวนอกสุดจริงหรือไม่
6. ไม่รวมแปลงข้างเคียงแม้มีรูปแบบปลูกคล้ายกัน
7. รักษารอยเว้าเมื่อเกิดจากคลอง น้ำเปิด หรือพื้นที่ไม่มีหลักฐาน
8. บริเวณที่แยกไม่ออกให้สร้าง `uncertain_boundary`

## 9. ห้ามทำ

- ห้ามใช้ Color Threshold ค่าเดียวเป็นคำตอบ
- ห้ามใช้ Convex Hull ปิดคลองหรือรอยเว้า
- ห้ามวงเฉพาะต้นที่รอดแล้วตัด Mortality Gap ออกทั้งหมด
- ห้ามตามคันดินหรือขอบน้ำโดยอัตโนมัติ
- ห้ามรวมแปลงข้างเคียงเพียงเพราะ Pattern เหมือนกัน
- ห้าม Smooth จนแนวขอบย้ายออกจากหลักฐาน
- ห้ามตั้งสถานะ `approved`
